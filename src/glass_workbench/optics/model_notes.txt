OFFLINE OPTICAL MODEL NOTES — verified 2026-10-20

Public wavelength arguments are vacuum micrometers. Refractive index returned
by dispersion.refractive_index is relative to the fixed catalog reference air,
not to a variable user atmosphere. Catalog spectral wavelengths use the familiar
air values (C=656.2725 nm, d=587.5618 nm, F=486.1327 nm). Public spectral constants
SPECTRAL_LINES_VACUUM convert these with dry Ciddor air at20C,101325Pa,450ppm CO2.
The precise catalog humidity/CO2 convention was not established: this is a
stated approximation, not an exact reconstruction of a manufacturer's lab.
Reference-air conversion outside Ciddor's .3..1.7um range is also an approximation
needed for source UV/IR checkpoints. Dispersion coverage is the supplied index
coverage, not transmission coverage. Polynomial CDGM NIR extrapolation is rejected
by default. N-BK7 on the catalog AIR axis at1.55um is1.5006520430195947;
the public VACUUM-axis result at1.55um is1.5006572571349939.

AUTHORITATIVE SOURCES READ
SCHOTT TIE-19, August2023, page2, equations2–7, downloaded from official site
and converted with Cherry's document converter:
https://media.schott.com/api/public/content/0dcd87a2d36942a3946d033f0a9065e6?v=940fa3fb&download=true
- Reference temperature20C; wavelength VACUUM um. Constants used as supplied,
  no extra ppm scaling. Relative reference n in (n^2-1)/(2n) explicitly permitted.
- n_abs(T)=n_rel(T0)*n_air_reference(T0)+prefactor*[D0*dT+D1*dT^2+D2*dT^3
  +(E0*dT+E1*dT^2)/(lambda_vac^2-lambdaTK^2)]. Differentiate this expression;
  n_rel=n_abs/n_air_user; dn_rel=(dn_abs-n_rel*dn_air_user)/n_air_user.
- Stated coefficient validity:0.365..1.014um, -100..140C. Thus1550nm requires
  explicit extrapolation even for SCHOTT Sellmeier glasses. The same document
  tabulates1060nm despite its stated1014nm limit. This inconsistency is disclosed,
  not silently resolved by widening the default range. Audit1060 uses opt-in.
- We deliberately use full Ciddor for air, not TIE19's approximate older air formula.

Ciddor1996, Applied Optics35,1566–1573 DOI10.1364/AO.35.001566.
NIST Stone/Zimmerman Engineering Metrology Toolbox documentation, sectionVII
Table1, retrieved and used as independent dry AND humid numerical test fixtures:
https://emtoolbox.nist.gov/wavelength/Documentation.asp
Ciddor equation constants cross-checked with published independent implementation:
https://github.com/polyanskiy/refractiveindex.info-scripts/blob/main/scripts/Ciddor%201996%20-%20air.py
- Full component-density/compressibility calculation with CO2 and humidity.
- NIST uses IAPWS saturation; this code uses Ciddor/Davis saturation. Tests allow
  2e-9 for that small difference and NIST's rounded table values, not a claimed
  physical accuracy. Ciddor physical uncertainty is much greater (see NIST).
- Public accepted envelope .3..1.7um,-40..100C,10..140kPa,0..2000ppmCO2.
  NIST accepts10..140kPa but warns outside60..120; Ciddor originally suggests
 80..120kPa. Accepted envelope MUST NOT be mistaken for guaranteed accuracy.
- RH fraction0..1, relative to ice below0C and water above. Reject x_water>=1.
  High RH/vapor fraction raises uncertainty and possible droplet formation.
- Five-point dn_air/dT at fixed pressure/CO2 and fixed RH by default, or fixed
  water mole fraction inferred from RH AT THE EVALUATION TEMPERATURE. Selecting
  fixed mole fraction changes the LOCAL DERIVATIVE, not air_index's state inputs.
  At the freezing branch boundary the derivative is one-sided.

UNVERIFIED APPROVED WORKING ASSUMPTION: both source n and source dn/dT are
nitrogen-relative, and nitrogen is approximated as dry Ciddor air at101325Pa,
450ppmCO2. N2 measurement conditions alone do not establish this convention.
Reference air follows temperature independently of the user's environment:
n_abs=n_source*n_air_reference; dn_abs=dn_source*n_air_reference
+n_source*dn_air_reference. Then divide by user Ciddor air and differentiate
that quotient. Source UV coverage outside Ciddor0.3..1.7um also needs opt-in.
This assumption is explicitly returned in warnings and is NOT independently
verified metrology. Native source evaluation is available separately for audit.

AGF CATALOG WORKSPACE — v0.3
AGF import is a separate raw-record/typed-inspection layer, not conversion into the
calculation Glass model. Existing calculation pools and first-sheet-only workbook
rules are unchanged. Preserve imported coefficient text, extra records, arbitrary
transmission thicknesses and source diagnostics; do not infer zero thermal response
from absent/empty TD. Unsupported local formulas remain inspectable and preservable.
Workbook exports use formula1 polynomial or formula2 Sellmeier with AGF paired
coefficient ordering. SI CTE is multiplied by1e6. PgF is not dPgF. Missing physical
data are not zero-filled. LD derived from spectral checkpoints is a working range,
not manufacturer-certified dispersion validity. All source assumptions and omissions
must remain visible in preview and accompanying provenance. Standard AGF export of
the bundled Corning/silicon models is not supported; no fitting is hidden in export.
